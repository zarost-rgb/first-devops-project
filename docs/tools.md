# Zainstalowane narzędzia DevOps

Lista podstawowych narzędzi skonfigurowanych w środowisku pracy wraz z ich krótkim opisem:

- **Git** — rozproszony system kontroli wersji, który pozwala śledzić zmiany w kodzie, wracać do poprzednich wersji i wygodnie pracować w zespole.
- **Docker** — platforma do uruchamiania aplikacji w izolowanych kontenerach, dzięki czemu program działa tak samo na moim komputerze i na serwerze produkcyjnym.
- **curl** — narzędzie wiersza poleceń do wysyłania zapytań sieciowych  i szybkiego testowania działania API lub pobierania skryptów instalacyjnych.
- **wget** — prosty program do pobierania plików z internetu bezpośrednio w terminalu przez protokoły HTTP, HTTPS i FTP.
- **unzip** — narzędzie do rozpakowywania archiwów `.zip`.
- **htop** — interaktywny monitor procesów w terminalu, który w czytelny sposób pokazuje zużycie procesora (CPU), pamięci RAM.
- **tree** — program wyświetlający strukturę katalogów i plików w postaci przejrzystego drzew.
- **jq** — lekkie narzędzie do parsowania, filtrowania i czytelnego formatowania danych w formacie JSON bezpośrednio w terminalu.
